# Créditos de assets — Pipeline Rush

## Propósito

Este archivo es el **registro obligatorio** de todos los assets externos (modelos, texturas, audio, fuentes, etc.) incluidos en el repositorio, conforme a la regla de **propiedad intelectual** de `AGENTS.md`.

- Cada asset externo que se añada al repo **debe** tener una fila en la tabla de abajo, en el mismo PR que lo introduce.
- Un asset sin registro aquí no se acepta en `master`.
- Está prohibido usar personajes, mascotas, logos, nombres, pistas, música, sonidos o assets de juegos o marcas de terceros, también "inspirados en" de forma reconocible.

## Licencias aceptadas

Solo se aceptan assets bajo una de estas dos categorías:

1. **CC0 1.0 (dominio público)** — https://creativecommons.org/publicdomain/zero/1.0/
2. **Generado para este proyecto** — creado específicamente para Pipeline Rush (a mano o con una herramienta), indicando la herramienta usada en la columna *Fuente*.

Cualquier otra licencia (CC-BY, CC-BY-SA, "free for personal use", licencias propietarias, etc.) **no** se acepta sin aprobación previa documentada en un ADR en `docs/`.
